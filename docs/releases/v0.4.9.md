### 修复 / Fixes

- **修复开启温控或固定转速时提示“控制服务未响应”、风扇冲高后又归零** — 部分 Mac 需要先解锁风扇手动模式，耗时可能超过 3 秒；此前 App 等待 3 秒即判定失败并断开连接，控制服务随之把风扇恢复为系统自动控制，导致每次切换都失败。现在等待时间按风扇数量和解锁所需的最长时间计算，退出 FanBar 也不再被缓慢的回复拖住
  **Fix "control service did not respond" and fans spinning up then dropping back to 0** — Some Macs must unlock manual fan mode first, which can take longer than 3 seconds. FanBar gave up after 3 seconds and dropped the connection, which made the control service restore automatic fan control, so every switch failed. The wait now scales with the fan count and the longest unlock time, and quitting FanBar no longer waits on a slow reply
- **控制服务新增诊断日志** — 记录每次风扇操作的耗时、真实错误和解锁时间，排查问题时可运行 `log show --predicate 'subsystem == "local.fanbar.helper"' --last 30m` 查看
  **Diagnostic logging for the control service** — Each fan operation's duration, underlying error, and unlock time are logged; view them with `log show --predicate 'subsystem == "local.fanbar.helper"' --last 30m`
- **修复控制模式错误提示与按钮文字重叠** — 错误提示显示时隐藏下方按钮，较长的提示不再溢出到相邻区域，完整内容可通过悬停或 VoiceOver 查看
  **Fix the control-mode error overlapping its buttons** — The buttons are hidden while the error is shown, long messages no longer overflow into neighboring sections, and the full text is available on hover and to VoiceOver
- **修复 macOS 26 及更新版本上设置窗口顶部标签图标拥挤** — 标签宽度改为跟随系统的原生尺寸
  **Fix crowded settings tab icons on macOS 26 and later** — Tab segments now use the system's native sizing
