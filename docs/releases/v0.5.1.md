### 修复 / Fixes

- **上下排列显示时 CPU 占用过高** — 菜单栏使用「温度在上、转速在下」显示方式时，即使关闭所有动画，FanBar 也会持续重绘状态栏，CPU 占用高达 40–60%。现在该模式下的 CPU 占用降至约 2% (#64)
  **High CPU with the stacked readout** — with the stacked temperature/fan-speed menu bar mode, FanBar redrew its status item nonstop and used 40–60% CPU even with every animation turned off. That mode now idles at about 2% CPU (#64)

### 优化 / Improvements

- **更低的内存占用** — 菜单面板改为首次打开时才创建，关闭一分钟后释放；设置窗口关闭后释放；App 内使用的自定义图标改用合适尺寸。启动后空闲内存从约 61 MB 降至约 27 MB (#64)
  **Lower memory use** — the menu panel is now built on first open and released a minute after it closes, the Settings window is released when closed, and the in-app copy of a custom app icon is sized for where it is drawn. Idle memory after launch drops from about 61 MB to about 27 MB (#64)
