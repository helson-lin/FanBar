### 修复 / Fixes

- **修复 Helper 退出时崩溃** — Helper 在收到 SIGTERM/SIGINT（关机、休眠、重装、App 退出）时因 Swift 并发隔离断言触发 SIGTRAP，导致无法恢复风扇自动控制；现已显式标记信号处理闭包为 `@Sendable`，退出路径稳定执行恢复逻辑
  **Fix helper crash on exit** — The helper trapped with SIGTRAP on SIGTERM/SIGINT (shutdown, sleep, reinstall, app quit) due to a Swift concurrency isolation assertion, skipping fan restore; the signal handler closures are now explicitly `@Sendable` so the shutdown path reliably restores automatic control
