### 新增 / New

- **自动恢复默认时长** — 设置 → 通用 → 风扇控制 新增"自动恢复系统控制"，可设为 15 分钟、30 分钟、1 小时或不自动恢复，每次切换到手动模式时按此计时。主界面中的修改只对当次生效，恢复系统控制后回到默认值 (#32)
  **Default automatic-restore duration** — Settings → General → Fan Control adds "Restore automatic control" (15 minutes, 30 minutes, 1 hour or never), used each time you switch to a manual mode. Changes in the menu apply to that session only and reset once control returns to macOS (#32)
- **可关闭主界面动画** — 设置 → 菜单栏 → 动画 新增"主界面动画"开关，关闭后风扇图形静止、模式切换无过渡，转速仍实时更新，可进一步降低 CPU 占用 (#32)
  **Panel animation can be turned off** — Settings → Menu Bar → Animation adds a "Panel animation" switch. When off, the fans stop spinning and mode changes don't animate while readings still update live, further lowering CPU use (#32)

### 改进 / Improvements

- **控制模式切换更顺滑** — 选中背景在模式之间平滑滑动；从"系统"切换到其他模式时控制条不再抖动；各模式按钮文字大小保持一致 (#32)
  **Smoother control mode switching** — the selection glides between modes, the strip no longer jolts when leaving Automatic, and all mode labels share one size (#32)
- **固定转速选中态** — "固定"选择器中当前转速（含自定义转速）以与控制条相同的背景高亮显示 (#32)
  **Fixed RPM selection** — the current RPM in the Fixed picker, including a custom value, is highlighted with the same background as the control strip (#32)
- **重新整理设置窗口** — 通用页合并为"风扇控制"、"通知"、"FanBar"三组；控制服务正常时收起为一行状态；统一行高、控件对齐与标题层级；"检查更新…"移至版本号旁 (#32)
  **Reorganized settings** — General is regrouped into Fan Control, Notifications and FanBar; a healthy control service collapses to a single status row; rows, controls and headers share one rhythm; "Check for Updates…" moves beside the version (#32)
- "硬件安全限制"更名为"自动恢复系统控制"，更准确地描述其作用
  "Hardware safety limits" is renamed "Restore automatic control" to better describe what it does
