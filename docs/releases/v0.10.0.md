### 新功能 / New Features

- **新增韩语界面** — FanBar 现在支持 한국어，菜单面板、设置、引导、控制反馈、兼容性报告、组件和命令行相关界面均已本地化。系统语言为韩语时会自动使用韩语，也可以在设置中即时切换，无需重新启动 (#163)
  **Korean interface** — FanBar now supports 한국어 across the menu panel, settings, onboarding, control feedback, compatibility reporting, widget and CLI-related interfaces. Korean is selected automatically when it is the system language, and can also be switched live in Settings without restarting (#163)

### 修复 / Fixes

- **修复菜单栏项目闪烁、消失和异常色块** — 移除了旋转状态图标使用的背景滤镜，避免部分 Apple 芯片、多显示器设备上的 WindowServer 反复重绘和菜单栏渲染损坏。FanBar 现在只在内容实际变化时更新菜单栏项目，并合并同一轮刷新中的重复更新；同时修复堆叠读数残留及资源项目过宽的问题 (#166)
  **Fixed flickering, disappearing items and colored blocks in the menu bar** — the spinning status icon no longer uses a backdrop filter, avoiding repeated WindowServer redraws and menu bar corruption seen on some Apple silicon, multi-display Macs. FanBar now updates menu bar items only when their content changes and coalesces duplicate work in each refresh; it also clears stale stacked readings and corrects overly wide resource items (#166)

### 注意 / Notes

- 本次更新不改变风扇控制协议、硬件转速边界、自动模式交还、存储格式或已有设置。
  This update does not change the fan-control protocol, hardware RPM bounds, hand-back to Automatic, storage formats or existing settings.
