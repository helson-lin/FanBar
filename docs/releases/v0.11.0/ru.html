Новое

  • Проверки обновлений теперь проходят через update.getfanbar.com, где анонимно подсчитываются по версии приложения и дате. Обмен анонимной статистикой использования по умолчанию выключен. При включении раз в неделю отправляются неделя установки, модель Mac, основная версия macOS и архитектура чипа; Cloudflare также предоставляет страну на основе сетевого расположения. Это можно изменить в настройках. Подробнее о конфиденциальности.
  • Выбирайте системный значок вентилятора или скрывайте его, оставив в строке меню только показания.
  • В настройки добавлена ссылка для обратной связи по электронной почте.

Исправления

  • Улучшены возврат управления вентиляторами системе macOS и переход к ручному управлению при замедлении вентилятора.
  • Исправлены выбор ранних точек кривой вентилятора, перенос подписи значения на новую строку и наложение показаний в строке меню.
