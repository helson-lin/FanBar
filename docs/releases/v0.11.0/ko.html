새로운 기능

  • 메뉴 막대에서 시스템 팬 아이콘을 선택하거나 아이콘을 숨기고 수치만 표시할 수 있습니다.
  • 설정에 이메일 피드백 링크가 추가되었습니다.
  • 업데이트 확인은 이제 update.getfanbar.com을 거치며 앱 버전과 날짜별 확인 횟수를 익명으로 집계합니다. 익명 사용 통계 공유는 기본적으로 꺼져 있습니다. 사용하면 설치 주, Mac 모델, macOS 주 버전과 칩 아키텍처가 매주 전송됩니다. Cloudflare는 네트워크 위치를 바탕으로 국가 정보도 제공합니다. 설정에서 변경할 수 있습니다. 개인정보 보호 상세 정보.

수정 사항

  • macOS에 팬 제어권을 돌려주는 처리와 팬이 감속 중일 때 수동 제어로 전환하는 처리를 개선했습니다.
  • 팬 곡선의 앞쪽 제어점을 선택할 수 없는 문제, 값 레이블이 줄바꿈되는 문제와 메뉴 막대 수치가 겹치는 문제를 수정했습니다.
