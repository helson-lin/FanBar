### 修复 / Fixes

- **记住手动模式目标转速并明确模式名称** — 此前选择与旧预设相同的固定转速不会被保存，切换模式再切回时可能恢复到旧值或默认转速。现在每次被控制服务接受的手动目标转速都会被记住（写入失败时保留上次保存的值），并将面板模式选择器与交还通知中的名称统一明确为“手动” (#186, #189)。

  **Remember manual fan targets and clarify mode name** — previously, a fixed target matching one of the old RPM presets was not saved, so switching modes and returning could revert to an older value or the default. Every target accepted by the helper is now remembered (keeping the previous value if a write fails), and the mode is consistently named "Manual" in the menu panel and hand-back notices (#186, #189).

- **统一设置页对齐并优化资源预览排版** — 统一设置各标签页分组标题与选项行的水平对齐，让右侧选择器按内容自然显示宽度，并将菜单栏设置中的系统资源预览调整为更紧凑的左对齐样式，同时为 `100%` 读数预留足够空间 (#187, #188)。

  **Align settings controls and compact resource previews** — aligned settings group headings with row content across tabs, let trailing pickers size naturally, and made the Menu Bar system resource previews left-aligned and more compact while reserving room for `100%` (#187, #188).

- **修复启动盘与 CPU 详情直接切换时的空白问题** — 在菜单面板中已展开启动盘或 CPU 详情后直接点另一项切换时，新展开的详情区域不再出现占高却空白的情况 (#191)。

  **Fixed blank detail area when switching between Startup Disk and CPU** — switching directly between the expanded Startup Disk and CPU details in the menu panel no longer leaves the newly opened detail blank (#191).
