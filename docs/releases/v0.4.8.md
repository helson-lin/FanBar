### 修复 / Fixes

- **修复开机登录启动时菜单栏图标偶发崩溃** — 当 FanBar 作为登录项被 launchd 在系统刚启动、WindowServer 连接尚未就绪时直接拉起，SwiftUI `App.init()` 阶段过早创建 `NSStatusItem` 会撞上 AppKit/SkyLight 的连接断言并直接 abort，表现为“一开机就崩溃、图标不出现”；现已将状态栏图标的创建延迟到 `applicationDidFinishLaunching`，此时 AppKit 已保证完成自身启动流程
  **Fix intermittent crash on launch-at-login** — When launchd started FanBar as a login item before the WindowServer connection was ready, creating an `NSStatusItem` too early inside SwiftUI's `App.init()` hit an AppKit/SkyLight connection assertion and aborted, showing up as "crashes on launch, icon never appears"; status-item creation now waits for `applicationDidFinishLaunching`, which AppKit only calls once its own startup sequence has finished
