### 新增 / New

- **自定义固定转速** — "固定"菜单新增"自定义转速…"，可以用滑块快速调整，或直接输入精确值（例如 3000 RPM）。可输入范围按本机风扇的硬件上下限计算并始终显示，超出范围时无法应用。最近一次使用的自定义转速会出现在菜单中，超出本机硬件范围的预设档位不再显示 (#26)
  **Custom fixed RPM** — the Fixed menu adds "Custom RPM…", with a slider for quick changes and a field for an exact value (e.g. 3000 RPM). The allowed range comes from this Mac's fan hardware limits and is always shown; values outside it can't be applied. The last custom value is listed in the menu, and presets outside the hardware range are hidden (#26)
- **可调整的高温提醒温度** — 设置 → 通知 新增"提醒温度"，可在 60–105°C 之间设置，默认 90°C。设置项默认收起，点击展开滑块；松开滑块后才生效，拖动过程中不会误发通知
  **Adjustable high-temperature alert** — Settings → Notifications adds "Alert temperature", configurable from 60–105°C (default 90°C). The row is collapsed by default and expands to a slider when clicked; the value applies when you release the slider, so dragging never triggers a stray notification

### 改进 / Improvements

- **大幅降低后台资源占用** — 菜单栏面板关闭时风扇动画完全暂停；菜单栏转动图标只在画面真正变化时重绘；系统服务状态不再每 2 秒查询；SSD 温度传感器在首次发现后复用。本地实测面板关闭时 CPU 占用从约 20% 降至约 3%（关闭菜单栏转动图标时）(#26)
  **Much lower background resource use** — fan animations fully pause while the menu bar panel is closed; the spinning menu bar icon only redraws when its image actually changes; system service status is no longer queried every 2 seconds; and the SSD temperature sensors are reused after the first discovery. In local measurement, CPU use with the panel closed dropped from about 20% to about 3% (with the spinning icon turned off) (#26)
- **菜单栏项目更紧凑** — 显示温度或转速时，菜单栏项目的宽度按实际读数计算，不再在图标和文字两侧留出多余空白
  **A tighter menu bar item** — when showing temperature or fan speed, the item's width is sized to the actual reading, removing the extra space around the icon and text
