### 修复 / Fixes

- **点击面板外可靠收起** — 增加应用内与全局鼠标事件监听，点击桌面、菜单栏、其他应用或 FanBar 自身窗口时均能收起面板，同时保留面板内部和状态栏图标的正常交互
  **Reliable click-outside dismissal** — Local and global mouse monitoring now closes the panel from the desktop, menu bar, other apps, or FanBar's own windows while preserving interactions inside the panel and on its status icon
- **统一面板展开颜色** — 展开前激活菜单栏应用并同步系统外观，使面板首次显示与点击后的颜色保持一致
  **Consistent panel appearance** — FanBar now activates and synchronizes the system appearance before presenting the panel, keeping its initial and focused colors consistent

### 安装 / Install

- Apple Silicon → `FanBar-0.4.5-arm64.dmg`
- Intel → `FanBar-0.4.5-x86_64.dmg`
- Universal → `FanBar-0.4.5.dmg`
- 校验和见对应的 `.sha256` 文件 / SHA256 checksums in corresponding `.sha256` files
