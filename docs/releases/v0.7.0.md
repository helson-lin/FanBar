### 新功能 / New Features

- **`fanbar` 命令行工具** — 在终端或脚本里查看状态、切换预设、设置固定转速或交还给 macOS：`fanbar status`、`fanbar preset set performance`、`fanbar mode fixed 3000`、`fanbar mode auto`。加 `--hold` 可让新模式一直保持到你改掉，不加时沿用设置里的自动恢复时间；`--json` 输出机器可读结果。FanBar 未运行时命令会在后台打开它。命令通过 FanBar 执行，只有当前用户能使用 (#107)
  **`fanbar` command-line tool** — read the status, switch presets, set a fixed speed or hand the fans back to macOS from Terminal or a script: `fanbar status`, `fanbar preset set performance`, `fanbar mode fixed 3000`, `fanbar mode auto`. `--hold` keeps the new mode until you change it; without it the Settings restore timer applies. `--json` prints machine-readable results. If FanBar isn't running, the command opens it in the background. Commands go through FanBar and only the current user can use them (#107)

- **在设置中一键安装命令行工具** — 设置 → 通用 → 命令行与自动化 → 命令行工具，点「安装…」即可把 `fanbar` 放到 `/usr/local/bin`，需要时只请求一次管理员密码。若终端会先找到别处的 `fanbar`，或 `/usr/local/bin` 不在 PATH 中，这一行会直接说明 (#107, #108)
  **Install the command-line tool from Settings** — Settings → General → Command Line & Automation → Command-line tool → Install… puts `fanbar` in `/usr/local/bin`, asking for an administrator password only when needed. The row tells you if your shell would find another `fanbar` first, or if `/usr/local/bin` isn't on your PATH (#107, #108)

- **Raycast 脚本命令** — 在 Raycast 中切换预设、设置固定转速、交还 macOS，并在根搜索里直接看到 CPU、GPU、SSD 温度。设置 → 通用 → 命令行与自动化 → Raycast，点「在 Raycast 中设置…」后，在 Raycast 中添加一次脚本目录即可；脚本会随 FanBar 更新，你改过的脚本不会被覆盖 (#107)
  **Raycast Script Commands** — switch presets, set a fixed speed, hand back to macOS, and see CPU, GPU and SSD temperatures right in Raycast's root search. In Settings → General → Command Line & Automation → Raycast, click Set Up in Raycast…, then add the script folder once in Raycast. The scripts update with FanBar, and scripts you edited are left as they are (#107)

### 修复 / Fixes

- **切换语言后，命令行与自动化区块同步更新** — 修复标题、说明和 CLI / Raycast 按钮残留上一种语言的问题。此次重新发布的内部构建号为 32，旧版 0.7.0 用户也可通过自动更新升级。
  **Command Line & Automation follows language changes** — fixed section headings, descriptions and CLI / Raycast buttons retaining the previous language. This replacement release uses build 32 so users of the earlier 0.7.0 can update automatically.

- **菜单面板标题和核心标签不再被截断** — 标题状态行改为「风扇正常 · macOS 控制 · CPU 65°」，放不下时在最后一段前换行；CPU 区的性能核 / 能效核标签按整格宽度排版，不再显示为「Performanc…」，也不再缩到 11pt 以下 (#105)
  **Panel header and core labels no longer truncate** — the header reads "Fans normal · macOS in control · CPU 65°" and breaks before its last part when a language doesn't fit; the CPU cell's performance / efficiency core labels use the full cell width instead of showing "Performanc…", and never shrink below 11pt (#105)

- **手动模式下的过热提示标题完整显示** — 恢复倒计时放不下时会换到提示下一行，不再把「CPU 平均温度偏高」等标题挤成省略号 (#106)
  **Alert titles stay whole in manual mode** — when the restore countdown doesn't fit beside an alert, it moves to the next line instead of truncating titles such as "CPU average is running warm" (#106)

### 注意 / Notes

- `fanbar` 需要 FanBar 正在运行（命令会自动打开它），切换模式前需已批准风扇控制服务。完整用法见 [docs/cli.md](https://github.com/helson-lin/FanBar/blob/main/docs/cli.md)
  `fanbar` works through the running FanBar (commands open it if needed), and switching modes needs the approved fan-control service. Full usage: [docs/cli.md](https://github.com/helson-lin/FanBar/blob/main/docs/cli.md)

- 升级后 FanBar 会自动重新注册风扇控制服务。如果系统提示，请在「系统设置 → 通用 → 登录项与扩展」中重新允许 FanBar
  After updating, FanBar re-registers its fan-control service automatically. If macOS asks, allow FanBar again in System Settings → General → Login Items & Extensions
