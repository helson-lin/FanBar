### 功能 / Features

- **可选菜单栏图标** — 新增六款菜单栏风扇图标（漩涡、圆环、粗体、螺旋桨、护罩、线框），在「设置 → 外观」中选择，默认为漩涡。各款图标已做视觉对齐，大小和粗细看起来一致；手动控制时中心变为实心，不只靠颜色区分 (#58)
  **Selectable menu bar icons** — six drawn fan glyphs (Swirl, Ringed, Bold, Propeller, Guard, Outline), chosen in Settings → Appearance; Swirl is the default. Glyphs are optically aligned so they read the same size and weight, and manual control shows a solid hub rather than relying on tint alone (#58)
- **温度与转速叠放显示** — 新增「温度在上、转速在下」的菜单栏显示方式，状态栏占用宽度减半 (#57, #58)
  **Stacked temperature and fan speed** — a new menu bar mode stacks the two readings, halving the status item's width (#57, #58)
- **繁體中文與日本語** — 新增繁体中文和日语界面，小组件同步支持；「跟随系统」会为 zh-Hant / TW / HK / MO 选择繁体中文，为 ja 选择日语 (#58)
  **Traditional Chinese and Japanese** — new interface languages, including the widget; the System language option picks Traditional Chinese for Hant/TW/HK/MO and Japanese for ja (#58)
- **可选 App 图标** — 设置中新增 App 图标选择器，分为材质和风格两组 (#56)
  **Alternative app icons** — an icon picker in Settings with Materials and Styles groups (#56)
- **设置面板重组** — 「菜单栏」面板更名为「外观」；告警温度改为内联步进器；版本、手动检查和自动检查合并为一行；登录时启动移入设置；菜单预设改用系统复选框，并改进键盘与 VoiceOver 操作 (#56)
  **Reorganized Settings** — the Menu Bar pane is now Appearance; the alert temperature uses an inline stepper; version, manual check and auto-check share one row; Launch at Login moves into Settings; menu presets use system checkboxes, with better keyboard and VoiceOver access (#56)
- **菜单栏预览与选项样式** — 「外观」中的菜单栏卡片重新显示模拟菜单栏的预览条，会跟随所选图标和上下排列模式；显示方式改为高亮当前选项，不再在每项之间加分隔线 (#62)
  **Menu bar preview and choice styling** — the Menu Bar card in Appearance shows the mock menu bar preview again, following the chosen icon and the stacked mode; display modes now highlight the current choice instead of dividing every option (#62)

### 修复 / Fixes

- **菜单栏图标变形** — 修正菜单栏风扇图标比例，旋转时在非 Retina 屏幕上也不再被裁切 (#51, #55)
  **Menu bar icon distortion** — fixed the fan icon's proportions; rotation no longer clips on non-Retina displays (#51, #55)
- **后台项目图标显示异常** — 修复「允许在后台」列表中 FanBar 小图标显示异常的问题（如 Mac mini 2014）(#50, #54)
  **Background item icon** — fixed FanBar's small icon rendering incorrectly in the Allow in the Background list, e.g. on a Mac mini 2014 (#50, #54)
