### 修复 / Fixes

- **兼容旧款 Intel Mac（如 Mac mini 2014）** — 没有 `F0Md`/`F0md` 模式键的机型不再报 `SMC operation F0Md failed (65668)`，改用 `FS! ` 位掩码切换手动模式；两者都没有时给出明确提示 (#40)
  **Older Intel Macs (e.g. Mac mini 2014) now work** — Macs without an `F0Md`/`F0md` mode key no longer fail with `SMC operation F0Md failed (65668)`; manual mode uses the `FS! ` bitmask instead, and a clear message is shown when neither exists (#40)
- **睡眠唤醒后保持手动风扇模式，恢复 GPU 温度读取** — 睡眠期间暂停自动恢复计时；XPC 超时后重新应用当前模式；自动恢复设为"从不"时不再 30 分钟后回到系统模式 (#41)
  **Manual fan mode survives sleep/wake, and GPU temperature reads again** — the auto-restore timer pauses during sleep, the current mode is re-applied after an XPC timeout, and "Never" no longer reverts after 30 minutes (#41)

### 安全 / Security

- **加固特权辅助程序** — 通过审计令牌（audit token）而非进程 ID 验证 XPC 调用方，并拒绝非有限值和负数转速 (#42)
  **Hardened the privileged helper** — XPC callers are verified by audit token instead of PID, and non-finite or negative RPM values are rejected (#42)
