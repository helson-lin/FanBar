### 新功能 / New Features

- **温度标题旁显示整机功耗** — 面板的「温度」标题后显示 Mac 当前的整机功耗（如「整机功耗 38 W」），与温度一起每 2 秒刷新。读数来自 SMC `PSTR`；不提供该键的 Mac（部分台式机和 Intel 机型）不显示。异常或过期的读数会被隐藏，不会显示猜测值 (#120, #76)
  **Whole-system power beside the Temperature heading** — the panel's Temperature heading now shows how much power the Mac draws (for example *Power 38 W*), refreshed with the temperatures every 2 s. The reading comes from SMC `PSTR`; Macs without that key (some desktops and Intel models) show nothing. Implausible or stale readings are hidden rather than guessed (#120, #76)

- **支持 FanBar 开发** — 设置 → 通用底部新增「支持 FanBar 的开发」链接。面板首次打开 14 天后会出现一次支持提示，选择「支持开发」或「不再显示」后不会再出现；它不会与过热、控制服务或模式切换失败的提示同时出现 (#119)
  **Support FanBar development** — Settings → General now has a *Support FanBar development* link. Fourteen days after the panel first opens, it shows a one-time support prompt; choosing *Support* or *Don't show again* dismisses it for good. It never appears alongside an overheat, control-service or mode-failure notice (#119)

### 修复 / Fixes

- **菜单栏图标旋转时内存占用大幅下降** — 0.7.1 中，旋转图标用来遮住静止图标的滤镜会让 Core Image 在内存中载入约 180 MB 的内核数据。现在改用不需要 Core Image 上下文的滤镜，效果相同。在 Mac mini M4 上，FanBar 的内存占用（活动监视器中的「内存」）从约 270 MB 降到约 90 MB (#121, #63)
  **Much lower memory use while the menu bar icon spins** — in 0.7.1, the filter that hides the still icon under the spinning one made Core Image load about 180 MB of kernel data into memory. It now uses a filter that needs no Core Image context and looks the same. On a Mac mini M4, FanBar's memory (the *Memory* column in Activity Monitor) drops from about 270 MB to about 90 MB (#121, #63)
