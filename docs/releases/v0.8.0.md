### 新功能 / New Features

- **自定义面板的监控模块** — 设置 → 外观 → 菜单栏面板，可以选择面板中部显示哪些模块（CPU、内存、GPU、启动盘）、按什么顺序排列。直接拖动预览或列表里的模块即可调整位置，用 ＋ / － 添加或移除，也可以右键或按 ⌥⌘↑ / ⌥⌘↓ 移动。模块数量为奇数时，最后一个占满整行；一个都不添加时，面板不再显示这一区域，整体更矮。默认仍是原来的 4 个模块，升级后面板不变 (#134)
  **Choose the panel's monitoring modules** — in Settings → Appearance → Menu Bar Panel, pick which modules the middle of the panel shows (CPU, Memory, GPU, Startup disk) and in what order. Drag a module in the preview or the list to move it, add or remove modules with + / −, or move them from the context menu or with ⌥⌘↑ / ⌥⌘↓. With an odd number of modules the last one spans its row; with none, the panel drops that area and gets shorter. The default is still the original four, so the panel looks the same after updating (#134)

- **查看占用 CPU 最多的应用** — 点按面板中的 CPU 格子，下方会列出占用 CPU 最多的 5 个应用，同一应用的辅助进程合并计算（例如浏览器的网页进程）。点一行打开活动监视器，右键可在访达中显示。只有展开时才会统计进程，收起或关闭面板即停止 (#135)
  **See which apps use the most CPU** — click the CPU cell in the panel to list the five apps using the most CPU beneath it, with each app's helper processes counted together (a browser's web content processes, for example). Click a row to open Activity Monitor, or Control-click to show the app in Finder. Processes are only measured while the list is open; collapsing it or closing the panel stops it (#135)

- **启动盘显示 SSD 温度** — 展开磁盘详情时，内置启动盘一行会显示 SSD 温度；接近上限时才变色提醒 (#134)
  **SSD temperature on the startup disk** — the internal startup disk's row in the disk details now shows the SSD temperature, and only changes color as it nears its limits (#134)

- **温控曲线可以跟随电池温度** — 散热 → 温度来源新增「电池」，只在有电池的 Mac 上提供 (#134)
  **Fan curves can follow the battery temperature** — Cooling → Temperature source now offers Battery on Macs that have one (#134)

### 改进 / Improvements

- **资源偏高时只用颜色提示** — CPU、GPU、内存负载偏高或磁盘空间偏低时，面板只把对应的进度条和核心柱变成橙色，不再额外写「偏高」「空间偏低」，让还不需要处理的状态不显得像警报。达到「很高」或「空间不足」时仍会写出文字。VoiceOver 两档都会读出状态
  **Elevated resource levels are shown by color alone** — when CPU, GPU or memory load is elevated or disk space runs low, the panel turns that resource's bars orange without adding "High" or "Space low", so a state that needs no action doesn't read like an alarm. "Very high" and "Almost full" are still spelled out, and VoiceOver announces both levels

### 注意 / Notes

- 应用列表的百分比按单核计算，与活动监视器一致，多核满载时可超过 100%。系统进程（如 kernel_task、WindowServer）需要管理员权限才能读取，因此列表只统计当前用户的进程。
  App percentages use Activity Monitor's scale, where one full core is 100%, so a busy app can exceed 100%. System processes such as kernel_task and WindowServer need administrator access to read, so the list covers the current user's processes only.
- 温控曲线只按所选的温度来源调速。选择「电池」或「SSD」时，风扇不会因 CPU 变热而加速。
  A fan curve follows only its selected temperature source. With Battery or SSD selected, the fans don't speed up because the CPU gets hot.
