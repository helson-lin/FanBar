### 修复 / Fixes

- **SMC 拒绝切回自动时也能把风扇交还 macOS** — 部分 Mac（例如 macOS 27.2 上的 M3 Max MacBook Pro）在交还风扇时会拒绝写入模式（"F0Md failed (65666)"），但手动写入仍然可以，所以只有「固定转速」能用，从曲线切走或切回自动都会提示"无法交还给 macOS"。现在 FanBar 会先退出风扇测试模式，再确认 macOS 是否已经接管，必要时重新写入一次 (#142)
  **Hands the fans back to macOS even when the SMC refuses to switch them to automatic** — some Macs, such as an M3 Max MacBook Pro on macOS 27.2, refuse the fan mode write when FanBar hands the fans back ("F0Md failed (65666)") while manual writes still work. Only Fixed mode worked there, and switching away from a curve or back to automatic reported "Couldn't hand back to macOS". FanBar now leaves the fan test mode first, checks whether macOS has taken the fans back, and writes the mode again if needed (#142)

- **交还失败时风扇不再停转** — 以前交还失败后，风扇可能停在手动模式、目标转速为 0，温度升高也不会转。现在仍处于手动模式的风扇会保持在最低转速，同时照常提示交还失败 (#142)
  **Fans no longer stop when the hand-back fails** — when the hand-back failed, a fan could be left in manual mode with a target of 0 RPM, so it stayed stopped even as the Mac got hotter. A fan still in manual mode is now held at its minimum speed, and the failure is still reported (#142)
