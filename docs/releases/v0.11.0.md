### 新功能 / New Features

- **更新检查与可选使用统计** — FanBar 现在通过 `update.getfanbar.com` 检查更新，它会跳转到 GitHub 并按应用版本和日期匿名统计检查次数。共享匿名使用统计默认关闭；同意后每周还会发送安装周、Mac 机型、macOS 主版本和芯片架构，Cloudflare 还会根据网络位置提供国家信息。可随时在设置中更改。详情见[隐私说明](https://github.com/helson-lin/FanBar/blob/main/services/update/PRIVACY.zh-CN.md) (#138)。

  **Update checks and optional usage statistics** — FanBar now checks for updates through `update.getfanbar.com`, which redirects to GitHub and anonymously counts checks by app version and day. Sharing anonymous usage statistics is off by default. If enabled, the install week, Mac model, macOS major version and chip architecture are also sent weekly; Cloudflare provides the country based on network location. This can be changed in Settings. See the [privacy notice](https://github.com/helson-lin/FanBar/blob/main/services/update/PRIVACY.md) (#138).

- **更多菜单栏图标选项** — 可选择系统风扇图标，或隐藏图标、仅显示读数 (#176, #178, #181)。

  **More menu bar icon options** — choose a system fan icon or hide the icon and show only readings (#176, #178, #181).

- **邮件反馈** — 设置中新增邮件反馈入口 (#182)。

  **Email feedback** — a new link in Settings opens an email to the FanBar team (#182).

### 修复 / Fixes

- **改善风扇控制切换** — 改进向 macOS 交还风扇的状态判断，并在风扇减速时给予切换到手动控制更多时间 (#170, #171, #179)。

  **Improved fan control transitions** — better recognize when macOS has taken control and allow more time to switch to manual control while a fan is slowing down (#170, #171, #179).

- **修复曲线和菜单栏显示** — 修复风扇曲线前面的控制点无法选择及数值标签换行的问题 (#180)，并修复菜单栏堆叠读数重叠。

  **Fixed curve editing and menu bar display** — earlier fan curve points can be selected and the value label stays on one line (#180); stacked menu bar readings no longer overlap.

### 安装 / Install

- Apple Silicon → `FanBar-v0.11.0-arm64.dmg`
- Intel → `FanBar-v0.11.0-x86_64.dmg`
- Universal → `FanBar-0.11.0.dmg`
- 校验和见对应的 `.sha256` 文件 / SHA256 checksums in corresponding `.sha256` files
